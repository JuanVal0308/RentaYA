# Prueba en dispositivo físico — RentaYa

Checklist para evidenciar la instalación real (requisito Entrega 3).

## Pasos

1. En el celular: **Ajustes → Opciones de desarrollador → Depuración USB** (activar).
2. Conectar el teléfono al PC con cable USB y autorizar el diálogo de depuración.
3. En Android Studio (carpeta del repo): elegir el dispositivo físico → **Run 'app'**.  
   Alternativa: instalar el APK debug  
   `app/build/outputs/apk/debug/app-debug.apk`  
   o el AAB de release vía Play Internal Testing / `bundletool`.
4. Recorrer: Onboarding → Registro/Login → Búsqueda → Detalle → Favoritos → Publicar → Mis publicaciones → Créditos.
5. Tomar **foto o video corto** del celular con la app abierta (pantalla de búsqueda o detalle).
